# Philips 55PUS7956/12 (TPV, PH0M_EA_T32, MStar/MediaTek), Italy -- personal variant
# Derived from examples/philips-50pud7406/debloat.txt (same board; its eighth unit is a 65PUS7956
# and its third unit a 55PUS7906/12, the same TV in another finish). NOT yet run on this unit.
#
# Before applying, check on the TV that it really is this platform:
#   adb shell getprop ro.product.device            -> PH0M_EA_T32
#   adb shell getprop persist.odm.tpv.fw.revision  -> TPM215E_... (Android 11)
# The set shipped with Android 10; the parent list was only tested on Android 11 and 14.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/philips-55pus7956/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/philips-55pus7956/debloat.txt
# Everything is DISABLED, not uninstalled. Apply in small batches and check the TV between them.
#
# Owner's constraints for this variant:
#   1. Ambilight untouched: org.droidtv.ambisvc and the Ambilight key are never disabled.
#   2. Google's ambient screensaver kept: com.google.android.backdrop stays enabled, so quirk 1 of
#      the parent list (screensaver pointing at a disabled component) does not apply.
#   3. Apps kept: Netflix, Prime Video, HBO Max, Crunchyroll, YouTube, RaiPlay, Witty TV.
#   4. Casting from a phone kept: com.google.android.apps.mediashell (Chromecast built-in) and
#      com.google.android.tv.remote.service (Google TV remote app) stay enabled.
#
# Known quirks inherited from the parent list:
#   - After a full reboot the firmware resumes Live TV (com.mediatek.wwtv.tvcenter) instead of Home.
#   - On the 65PUS7956 unit, YouTube and Disney+ sign-in failed with Private DNS on: leave it off.
#   - 1.38 GB RAM, ro.config.low_ram=true: every background service removed helps.
